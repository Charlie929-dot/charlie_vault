### 一、GNU C/C++ 是什么？

GNU C/C++ 本质上是**GNU 项目**对 C/C++ 语言的实现，核心由两部分组成：

#### 1. 核心工具链

- **GCC（GNU Compiler Collection）**：GNU 编译器套件，是实现 GNU C/C++ 的核心。早期 GCC 是 “GNU C Compiler”（仅支持 C），后来扩展为支持 C++、Java、Go 等多语言的编译器集合，其中：
    - `gcc` 命令：默认编译 C 代码（也可通过参数编译 C++）；
    - `g++` 命令：专门编译 C++ 代码（自动链接 C++ 标准库，处理 C++ 特性更友好）。
- **GNU 扩展**：GCC 对标准 C/C++ 做了大量实用扩展（比如 `__attribute__`、语句表达式、变长数组（VLAs）等），这些扩展不属于标准，但在 Linux 等系统中广泛使用（常说的 “GNU C” 也特指带这些扩展的 C 语言）。

#### 2. 生态关联

GNU C/C++ 是 Linux 系统的默认 C/C++ 编译环境，搭配 GNU 库（如 `glibc`（C 标准库）、`libstdc++`（C++ 标准库）），构成了类 Unix 系统下 C/C++ 开发的基础。

### 二、C 语言版本（标准）

C 语言的标准由 **ISO/IEC** 制定，核心版本如下（按时间排序）：

|版本|发布年份|别称 / 关键特性|备注|
|---|---|---|---|
|C89/C90|1989/1990|ANSI C / ISO C90<br><br>核心特性：标准化语法、函数原型、预处理、基本数据类型|第一个官方标准，最基础|
|C99|1999|新增：变长数组（VLA）、`long long`、复数类型、`//` 单行注释、`restrict` 关键字|GCC 全面支持，部分编译器（如 MSVC）支持不全|
|C11|2011|新增：原子操作、线程支持、`_Generic` 泛型、边界检查函数（如 `strcpy_s`）|重点补充并发特性|
|C17/C18|2017/2018|仅对 C11 的勘误 / 修正，无新特性|常统称 C17|
|C23|2023|新增：`bool` 关键字（无需头文件）、`static_assert` 无参数、改进整数类型等|最新标准，逐步被编译器支持|

> 补充：GCC 对 C 标准的支持可通过编译参数指定，比如 `-std=c99`、`-std=c11`、`-std=gnu11`（GNU 扩展版 C11）。

### 三、C++ 语言版本（标准）

C++ 标准同样由 ISO/IEC 制定，俗称 “C++XX”（如 C++11），核心版本如下：

|版本|发布年份|别称|关键特性（核心）|备注|
|---|---|---|---|---|
|C++98|1998|第一个 C++ 标准|标准化面向对象、STL 基础、异常、命名空间|奠定 C++ 基础|
|C++03|2003|-|仅对 C++98 的勘误，无新特性|过渡版本|
|C++11|2011|C++0x|智能指针（`unique_ptr`/`shared_ptr`）、Lambda 表达式、范围 for、`auto`、移动语义|里程碑版本，彻底升级 C++|
|C++14|2014|-|对 C++11 的补充：`auto` 函数返回值、Lambda 捕获表达式、二进制字面量|小幅度增强|
|C++17|2017|-|结构化绑定、`std::optional`/`variant`/`any`、并行算法、`constexpr` 增强|完善现代 C++ 特性|
|C++20|2020|-|概念（Concepts）、协程、模块（Modules）、范围（Ranges）、`std::format`|重大升级，解决历史痛点|
|C++23|2023|-|静态多态、`std::print`、改进协程 / 模块、`std::mdspan`|最新标准，持续完善|

> 补充：
> 
> 1. GCC 对 C++ 标准的支持：通过 `-std=c++11`、`-std=c++17`、`-std=c++20` 等参数指定，新版 GCC 已全面支持 C++20/23 大部分特性；
> 2. 行业现状：目前主流使用 C++11/17，C++20 逐步普及（模块、Ranges 是重点）。

### 四、总结

1. **GNU C/C++** = GCC 编译器 + GNU 扩展 + GNU 标准库（glibc/libstdc++），是类 Unix 系统下 C/C++ 开发的核心；
2. C 语言版本：从 C89 到 C23，侧重稳定性和底层支持，新增特性少而精；
3. C++ 语言版本：从 C++98 到 C++23，迭代极快，C++11 是分水岭，现代 C++ （11/17/20）大幅提升开发效率。

如果需要验证编译器对某个版本的支持，可通过 `gcc -v` 查看 GCC 版本，或用 `__STDC_VERSION__`（C）、`__cplusplus`（C++）宏判断当前编译标准。
