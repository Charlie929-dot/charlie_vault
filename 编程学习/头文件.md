# <stdio.h>——输入/输出库中的scanf()、printf()、getchar()、putchar()函数等；
# <math.h>——数学库中的pow()、sin()、cos()、abs()、fabs()、exp()函数等；
- `pow()`：计算幂运算（如`pow(2,3)`表示 2 的 3 次方）；
- `sin()`/`cos()`：计算正弦、余弦值（参数为弧度制）；
- `abs()`：计算整数的绝对值；
- `fabs()`：计算浮点数的绝对值；
- `exp()`：计算自然指数（以 e 为底的幂运算，如`exp(1)`表示 e 的 1 次方）。
- `sqrt()`：平方根
- `log()`：自然对数
# <ctype.h>——字符库中的isalnum()、isalpha()、isdigit()、islower()、isupper()函数等；
# <stdlib.h>——标准库中的malloc()、calloc()、realloc()、free()、system()、atoi()、rand()、srand()、exit()函数等。
`malloc()`  动态分配指定字节数的内存空间，返回指向该空间的指针（未初始化）                  
`calloc()`   动态分配内存并初始化为 0，参数为 “元素个数 + 单个元素字节数”            
`realloc()` 调整已分配内存的大小，可扩展或缩小原内存块                        
`free()`     释放由`malloc()`/`calloc()`/`realloc()`分配的动态内存，避免内存泄漏 
`system()`  调用操作系统命令（如`system("pause")`在 Windows 中暂停程序）        
`atoi()`    将字符串转换为整数类型（如`"123"`转为`int`型的 123）              
`rand()`    生成伪随机整数（范围通常为 0~RAND_MAX）                        
`srand()` 设置`rand()`的随机数种子（通常结合`time()`使用，避免每次随机序列相同）        
`exit()`   终止程序运行，参数为退出状态码（0 表示正常退出，非 0 表示异常）
